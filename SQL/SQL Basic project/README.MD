# Автосалон "Врум-Бум"

## Описание подхода при нормализации  

Анализ сырых данны выявил, что сырые данные содержат информацию о продажах автомобили. Из таблицы выделены две сущности:

- Покупатели
- Автомобили  

Покупатели были вынесены в отдельную таблицу содержащую полное имя покупателя и его телефон.

Наименование автомобилей было разделены на таблицы: цвет, брэнд, модель.
